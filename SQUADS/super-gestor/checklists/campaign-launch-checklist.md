# Checklist de Lançamento de Campanha

Use antes de publicar qualquer campanha criada pelo super-gestor.

## Perfil do médico
- [ ] Nome completo visível no perfil
- [ ] CRM + estado + palavra "MÉDICO" visível
- [ ] Especialidade + número RQE visível

## Conteúdo / Criativo
- [ ] Nenhuma promessa de "resultado garantido"
- [ ] Linguagem sem sensacionalismo
- [ ] Se tem antes/depois: texto educativo + indicações + complicações incluídas
- [ ] Imagens não foram manipuladas digitalmente

## Infraestrutura técnica
- [ ] Pixel do Meta instalado e disparando
- [ ] Google Tag Manager ativo no site
- [ ] Site tem política de privacidade (LGPD)
- [ ] Formulário/quiz tem consentimento de coleta expresso
- [ ] Orçamento calculado com fator 0,878 (imposto Meta)

## Histórico
- [ ] Estrutura registrada em campaign-history.yaml com status EM_TESTE
- [ ] ID do experimento anotado (EXP-XXX)

## Pós-lançamento (7-14 dias)
- [ ] Reportar resultado ao traffic-chief
- [ ] Atualizar status para VALIDADA ou DESCARTADA
- [ ] Registrar CPA real e notas no histórico
