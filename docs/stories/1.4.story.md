## Story

**As a** usuário da calculadora,
**I want** ver um histórico dos meus cálculos anteriores que persiste entre sessões,
**so that** eu possa consultar resultados passados e reutilizar expressões sem precisar digitá-las novamente.

- Persistência via `localStorage` com chave `calculadora_historico`, máximo 50 itens
- Itens ordenados do mais recente para o mais antigo (prepend)

## Acceptance Criteria

1. Após calcular `2 + 3`, o painel de histórico exibe uma entrada com expressão `2+3` e resultado `= 5`
2. Após fechar e reabrir a calculadora (F5 / recarregar), o histórico continua visível — os dados persistem via `localStorage`
3. O botão **Limpar histórico** apaga todos os itens do painel e remove a chave `calculadora_historico` do `localStorage`
4. Ao acumular mais de 50 cálculos, apenas os 50 mais recentes são mantidos — o 51º item mais antigo é descartado automaticamente
5. Clicar em um item do histórico carrega sua expressão no display da calculadora
6. Se o `localStorage` estiver vazio ou a chave não existir, o painel exibe a mensagem `Nenhum cálculo ainda`
7. Erros de parse no `localStorage` (JSON corrompido) não travam a aplicação — o `load()` retorna `[]` com segurança

## Dev Notes

### Estrutura de um item do histórico

```javascript
// Formato armazenado no array (e no localStorage como JSON)
{
  expression: "sin(30)",   // string da expressão inserida pelo usuário
  result: 0.5              // valor retornado por MathParser.evaluate()
}
```

### Implementação completa esperada do HistoryManager

```javascript
const HistoryManager = {
  MAX_ITEMS: 50,
  STORAGE_KEY: 'calculadora_historico',

  load() {
    try {
      const raw = localStorage.getItem(this.STORAGE_KEY);
      return raw ? JSON.parse(raw) : [];
    } catch {
      return [];
    }
  },

  save(items) {
    localStorage.setItem(this.STORAGE_KEY, JSON.stringify(items));
  },

  add(expression, result) {
    const items = this.load();
    items.unshift({ expression, result });
    this.save(items.slice(0, this.MAX_ITEMS));
  },

  clear() {
    localStorage.removeItem(this.STORAGE_KEY);
  },

  getAll() {
    return this.load();
  }
};
```

### Alteração em Calculator.init()

Adicionar ao final do método `init()`, após os bindings de eventos:

```javascript
// Restaurar histórico persistido ao abrir a calculadora
this.renderHistory();
```

### Por que `getAll()` chama `load()` e não usa um array interno?

A arquitetura escolhida é **stateless** — cada operação lê e escreve direto no `localStorage` sem manter estado em memória. Isso simplifica o código (sem sync de estado) e garante consistência automática. O custo (múltiplos JSON.parse por cálculo) é irrelevante para o volume de dados (máx. 50 itens, JSON pequeno).
