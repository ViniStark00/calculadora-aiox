# ETS-004.04 — Agente Criador: Briefing + Criação Pausada

## User Story

**Como** gestor de tráfego (Vinicius),
**quero** acionar o Criador com um briefing em linguagem natural e receber uma hierarquia completa de campanha criada no Meta Ads em estado PAUSED,
**para que** eu possa revisar antes de qualquer gasto real de verba — sem precisar preencher campos técnicos nem conhecer os IDs da conta.

---

## Contexto

O Criador é o agente de entrada do squad. É o único que interage com o gestor para coletar o briefing. Ele orquestra a FASE 0 (ETS-004.02) e o pipeline de assets (ETS-004.03) e, ao final, cria a hierarquia completa em estado PAUSED.

**Princípios inegociáveis:**
- Briefing **one-shot** — exibe tudo de uma vez, interpreta a resposta em linguagem natural (RQ-UX-001)
- Campos ausentes agrupados em **uma única mensagem** com padrão visível (DA-B14)
- Conta de anúncios **nunca assumida** — pergunta explicitamente se não informada (DA-B12)
- Público **sempre escolhido pelo gestor** da lista numerada — nunca automaticamente (DA-B02)
- Nomenclatura de campanha/conjunto/anúncio montada **automaticamente** pelo Criador (seção 15 do DESIGN.md)
- Criação sempre em **PAUSED** — nunca ativa diretamente

**Dependências:**
- ETS-004.02: `tasks/resolver-ids.md` (FASE 0) já implementada
- ETS-004.03: `scripts/upload_images.py`, `scripts/upload_video.py` já implementados

**Bloqueia:** ETS-004.05 (Revisor precisa do Criador para ter algo a revisar)

### tasks/coletar-briefing.md — Briefing e Interpretação

- [x] A task instrui o Criador a identificar o **tipo de campanha** antes de exibir o briefing:
  ```
  Qual tipo de campanha vamos criar?
  1. Vendas (WhatsApp, site ou landing page)
  2. Tráfego (link externo)
  3. Leads (formulário do Meta)
  4. Engajamento (post ou vídeo)
  ```
- [x] Para cada tipo, exibir o briefing completo **de uma vez** (one-shot, RQ-UX-001) com todos os campos relevantes — nunca campo a campo
- [x] O briefing de **Vendas** inclui os 16 campos do DESIGN.md seção 4 (nome, conta, destino, link, pasta Drive, formato, público, orçamento, ADV+ Audience, ADV+ Creative, posicionamentos, message, headline, localização, faixa etária, gênero)
- [x] Os briefings de **Tráfego**, **Leads** e **Engajamento** adaptam os campos ao objetivo (ex: Leads inclui pergunta sobre formulário existente ou criar novo; Engajamento inclui pergunta sobre post a impulsionar vs. dark post)
- [x] Após resposta do gestor, a task instrui o Criador a **interpretar em linguagem natural** usando a tabela RQ-UX-002 do DESIGN.md:
  - "whats" / "zap" → `destination_type: WHATSAPP`
  - "reels e stories" → placement explícito
  - "ADV+ tudo off" → `advantage_audience: 0` + `is_dynamic_creative: false` + `automatic_manual_state: MANUAL`
  - "R$ 50" / "50 reais" → `daily_budget: 5000` (×100 obrigatório)
  - "carrossel" → formato `child_attachments`
  - "vendas" / "tráfego" / "leads" / "engajamento" → ODAX correspondente
- [x] Após interpretar a resposta, a task instrui a verificar **campos obrigatórios não informados** e agrupá-los numa **única mensagem** com padrão visível (DA-B14):
  ```
  Alguns campos não foram informados. Responda ou pressione Enter para usar o padrão:

  Localização? (ex: BH 40km) ← obrigatório, sem padrão
  Faixa etária? (padrão: 18-65+)
  Gênero? (padrão: todos)
  Posicionamento? (padrão: automático)
  Período de veiculação? (padrão: sem data de fim)
  ```
- [x] A task instrui: campos com padrão seguro mostram o padrão entre parênteses; campos sem padrão (localização, link de destino) são marcados como obrigatórios — bloquear se não respondidos
- [x] A task instrui: nunca repetir campo que o gestor já respondeu na mensagem de follow-up
- [x] Saída: `briefing_interpretado` com todos os campos mapeados para parâmetros da API

  ```
  Confirmar ou digitar "AJUSTAR nome" para corrigir:
  ```

#### Criação da campanha (ads_create_campaign)

- [x] Criar campanha com `status: PAUSED` e parâmetros do briefing:
  - `name`: nome montado pela nomenclatura
  - `objective`: ODAX resolvido (ex: `OUTCOME_TRAFFIC`)
  - `status`: `PAUSED` — **obrigatório, nunca ACTIVE**
  - `special_ad_categories`: `[]` (lista vazia — padrão para campanhas comuns)
- [x] Capturar `campaign_id` da resposta
- [x] Se `ads_create_campaign` falhar: reportar erro e parar — nunca prosseguir sem `campaign_id`

#### Criação do conjunto de anúncios (ads_create_ad_set)

- [x] Criar conjunto com `status: PAUSED` e os campos:
  - `name`: nome montado pela nomenclatura
  - `campaign_id`: do step anterior
  - `billing_event`: `IMPRESSIONS`
  - `optimization_goal`: derivado do mapa objetivo + destino (seção 10 do DESIGN.md)
  - `daily_budget`: em centavos (`daily_budget_brl × 100`) — **conversão obrigatória (DA-B07)**
  - `targeting`: geo + público customizado:
    ```python
    {
      "geo_locations": {"cities": [...]},  # ou countries se não houver cidade
      "custom_audiences": [{"id": audience_id}],
      "targeting_automation": {"advantage_audience": 0}  # se ADV+ off
    }
    ```
  - `promoted_object`: conforme objetivo (ex: `{"page_id": page_id}` para tráfego; `{"pixel_id": pixel_id, "custom_event_type": "PURCHASE"}` para vendas com pixel)
  - Campos ADV+ explícitos conforme briefing (DA-B08):
    - `is_dynamic_creative: false` (se ADV+ Creative off)
    - `is_dynamic_creative_format_automation: false`
    - `automatic_manual_state: "MANUAL"` (se posicionamento manual)
- [x] Capturar `ad_set_id` da resposta
- [x] Se `ads_create_ad_set` falhar: reportar erro e parar

#### Criação dos anúncios (ads_create_ad) por formato

- [x] A task instrui criação diferente por formato:

  **Formato: Imagem**
  ```
  1. ads_create_creative(image_hash + link_url + page_id + CTA)
     → creative_id
  2. ads_create_ad(ad_set_id + creative_id + status: PAUSED)
     → ad_id
  ```
  - Um anúncio por imagem retornada pelo pipeline Drive → Meta

  **Formato: Vídeo**
  ```
  1. ads_create_ad com object_story_spec + video_data:
     {
       "video_id": "...",
       "image_hash": thumbnail_hash,   ← obrigatório (DA-B05)
       "message": "...",
       "call_to_action": {
         "type": "LEARN_MORE",         ← nunca incluir value.link em WHATSAPP_MESSAGE (DA-B10)
       }
     }
  status: PAUSED
  ```

  **Formato: Carrossel estático** (DA-B04)
  ```
  ads_create_ad inline com object_story_spec + link_data + child_attachments[]:
  [
    {"image_hash": hash1, "link": url, "name": "Card 1"},
    {"image_hash": hash2, "link": url, "name": "Card 2"},
    ...
  ]
  status: PAUSED
  Nota: NÃO usar ads_create_creative para carrossel — não suporta (DA-B04)
  ```

- [x] Capturar todos os `ad_id` criados em lista
- [x] Se qualquer `ads_create_ad` falhar: reportar qual anúncio falhou, continuar com os demais, registrar na saída

- `OUTCOME_LEADS`: `{"page_id": page_id}`

**Regra de confirmação dos nomes (seção 15):**
O Criador exibe os nomes montados **antes de criar**. Se o gestor responder `AJUSTAR nome`, o Criador corrige e exibe novamente antes de prosseguir. Apenas após confirmação (silêncio ou "ok") é que cria no Meta.

**Verificação leadgen_tos para OUTCOME_LEADS:**
Se objetivo for leads, verificar (via FASE 0) se a página aceitou os Termos de Serviço do Lead Ads. Se `leadgen_tos_accepted: false`, bloquear com mensagem antes de criar — a API rejeitará o anúncio.
