## Story

**As a** usuário da calculadora,
**I want** abrir o `index.html` no navegador e ver a estrutura da calculadora carregada com display e botões visíveis,
**so that** eu tenha a base visual e técnica funcionando sobre a qual todas as outras features serão construídas.

## Acceptance Criteria

1. A pasta `calculadora/` existe na raiz do projeto com exatamente três arquivos: `index.html`, `style.css`, `script.js`
2. O `index.html` carrega sem nenhum erro no console do navegador (zero erros, zero warnings)
3. O display principal é visível com duas áreas distintas: uma para a expressão em construção e outra para o resultado
4. A grade de botões numéricos (0–9), ponto decimal (`.`) e operadores básicos (`+`, `-`, `×`, `÷`, `=`, `C`, `CE`) está renderizada e visível
5. O painel de histórico (vazio inicialmente) está visível na interface com título e botão "Limpar Histórico"
6. O layout é responsivo: utilizável em viewport de 320px de largura (mobile) e 1280px (desktop)
7. Os botões respondem ao click com feedback visual (hover/active state)
8. O arquivo `script.js` define os quatro objetos globais: `MathParser`, `ScientificFunctions`, `HistoryManager`, `Calculator` (podem ser stubs sem lógica ainda)
9. O toggle "Básico / Científico" está visível e ao clicar alterna a classe CSS do keypad (mostra/oculta botões científicos), mesmo que os botões científicos ainda não calculem nada
10. O toggle "Graus / Radianos" está visível com estado visual de qual está ativo

## Dev Notes

### Contexto da Arquitetura

Esta story cria a **fundação** da calculadora. As Stories 1.2, 1.3 e 1.4 vão preencher os stubs com lógica real — por isso é crítico que os nomes de objetos, métodos e classes CSS estejam corretos aqui.

### Estrutura de arquivos esperada ao final desta story

```
calculadora/
├── index.html
├── style.css
└── script.js
```

### Atributos `data-*` obrigatórios nos botões

O `Calculator.init()` usa **event delegation** — um único listener em `.keypad` captura todos os cliques. Cada botão DEVE ter `data-action` e opcionalmente `data-value`:

```html
<!-- Dígitos -->
<button data-action="append" data-value="7">7</button>

<!-- Operadores básicos -->
<button data-action="append" data-value="+">+</button>
<button data-action="append" data-value="*">×</button>

<!-- Ações especiais -->
<button data-action="calculate">=</button>
<button data-action="clear">C</button>
<button data-action="backspace">CE</button>

<!-- Funções científicas (ficarão em .scientific-buttons) -->
<button data-action="append" data-value="sin(">sin</button>
<button data-action="append" data-value="Math.PI">π</button>

<!-- Toggles (fora do keypad, no .mode-toggles) -->
<button id="toggle-mode" data-mode="basic">Científico</button>
<button id="toggle-angle" data-angle="deg">RAD</button>
```

### Botões necessários no HTML

**Básicos (`.basic-buttons`):**
`7`, `8`, `9`, `÷`
`4`, `5`, `6`, `×`
`1`, `2`, `3`, `-`
`0`, `.`, `=`, `+`
`C`, `CE`, `%`, `( )`

**Científicos (`.scientific-buttons`):**
`sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹`
`ln`, `log`, `x²`, `xⁿ`, `√`, `|x|`
`n!`, `π`, `e`

### Variáveis CSS obrigatórias

Definidas no `:root` — serão usadas por todas as stories subsequentes:
```css
:root {
  --bg-primary: #1a1a2e;
  --bg-secondary: #16213e;
  --bg-button: #0f3460;
  --accent-blue: #533483;
  --accent-orange: #e94560;
  --text-primary: #eaeaea;
  --text-dim: #888;
  --border-radius: 8px;
  --transition: 0.15s ease;
}
```

### Stubs do `script.js`

Os objetos precisam existir no escopo global (sem `export`) para que as Stories 1.2–1.4 possam expandi-los. Stubs silenciosos são aceitos — o importante é que nenhum erro seja lançado ao clicar.
