# GTS-001.07 — QA e Testes de Integração

## User Story

**Como** gestor de tráfego prestes a usar o squad `gestor-trafego-stark` em produção,
**quero** que um agente QA valide a completude estrutural, a consistência de referências
e o fluxo do pipeline antes do lançamento,
**para que** eu não descubra erros de configuração no primeiro uso real.

---

## Contexto

O QA é executado sobre o squad completo, após todas as etapas 5A–5E estarem concluídas.
O @qa não cria nem edita arquivos além do `QA-REPORT.md`.
Se qualquer critério falhar, o relatório lista o problema específico e o arquivo afetado.
O squad só pode avançar para a Etapa 7 (PR) se todos os 7 critérios estiverem PASS.
