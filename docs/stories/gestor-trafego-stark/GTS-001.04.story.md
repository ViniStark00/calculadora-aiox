# GTS-001.04 — Agentes Tier 1 Grupo A (Pipeline de Relatório)

## User Story

**Como** stark-chief executando a rotina-semanal,
**quero** agentes especializados que coletam métricas, geram narrativa, publicam no Reportei
e formatam a mensagem WhatsApp,
**para que** cada etapa do pipeline seja executada por um agente com responsabilidade única
e outputs verificáveis pelo validator.

---

## Contexto

Estes 5 agentes formam o núcleo do pipeline de relatório semanal, herdado do squad Vinicius.
Todos devem ser **reescritos do zero** para o novo squad, com as seguintes extensões:

- **coletor**: aceita `metricas_coletadas` como parâmetro opcional (DESIGN.md seção 3.2)
- **redator**: referencia `data/thresholds-por-especialidade.yaml` (novo caminho/schema)
- **publicador**, **whatsapp-writer**, **contexto-cliente**: referenciam `data/clientes.yaml`

Referências de conteúdo (apenas leitura):
- `squads/gestor-trafego-vinicius/agents/` — todos os 5 agentes localmente disponíveis

## Critérios de Aceite

### agents/coletor.md

**Identidade:**
- [ ] `tier: 1`
- [ ] `squad: gestor-trafego-stark`

**Fonte de dados:**
- [ ] Fonte primária: Reportei API via `get_project_metrics` e `get_metrics` (MCP Reportei)
- [ ] Fonte alternativa: Meta Ads MCP (quando Reportei falhar)
- [ ] Referencia `data/clientes.yaml` para obter `reportei_project_id` e `sheet_columns`

**Reuso de dados (extensão crítica):**
- [ ] Aceita parâmetro opcional `metricas_coletadas` (dict keyed por slug do cliente)
- [ ] Quando `metricas_coletadas[slug]` existe E `fonte` é desta semana: usa os dados sem nova chamada Meta Ads
- [ ] Mesmo com `metricas_coletadas` fornecido: SEMPRE busca Google Ads e seguidores via Reportei (não estão no Meta Ads MCP)
- [ ] Documenta no output qual fonte foi usada para cada métrica (metricas_coletadas vs API)

**Preenchimento do Sheets:**
- [ ] Executa `fill_sheets.py` com os dados coletados
- [ ] Usa `sheet_columns` do cliente em `data/clientes.yaml` para mapear colunas
- [ ] Verifica exit code do script — falha = retornar ao stark-chief com mensagem clara
- [ ] Período: segunda a domingo da semana anterior (calculado automaticamente)

**Slugs de métricas corretos (do squad Vinicius):**
- [ ] Google Ads spend: `"google_adwords"` (NÃO `"google_ads"`)
- [ ] Seguidores: `"ig:new_followers_count"`
- [ ] Conversas: `"messaging_conversation_started_7d"`
- [ ] Google cost unit: direto (sem ÷ 1.000.000)

**Tasks que executa:**
- [ ] `tasks/fetch-metrics.md` → coleta as métricas
- [ ] `tasks/verify-fill.md` → valida dados antes de escrever no Sheets
- [ ] `tasks/save-history.md` → salva histórico em `data/historico-clientes.yaml`

### agents/redator.md

**Identidade:**
- [ ] `tier: 1`
- [ ] `squad: gestor-trafego-stark`

**Regras de voz (lista completa — idêntica ao CLAUDE.md):**
- [ ] Palavras proibidas (elogios) documentadas: incrível, surpreendente, excelente, extraordinário, impressionante, fantástico, brilhante, notável
- [ ] Palavras proibidas (críticas): preocupante, alarmante, crítico, péssimo, desastroso, infelizmente
- [ ] Jargão de IA proibido: alavancar, potencializar, maximizar, robusto, sinergia, ecossistema, transformador, impactante
- [ ] Frases de IA proibidas: "é importante ressaltar", "cabe destacar", "vale salientar", "nesse sentido", "isso posto", "outrossim", "observa-se que"

**Classificação por threshold:**
- [ ] Referencia `data/thresholds-por-especialidade.yaml` (novo caminho)
- [ ] Usa `especialidade` do cliente em `data/clientes.yaml` para selecionar bloco correto
- [ ] Tom calibrado: saudavel → neutro; atencao → neutro com observação; critico → neutro com alerta (sem palavras proibidas)

**Geração de HTML:**
- [ ] Gera HTML de timeline para o marco do Reportei
- [ ] HTML contém pelo menos: spend, leads, CPL, CTR, CPM
- [ ] HTML sem tags abertas sem fechar (verificável pelo gate_reportei)

**Condicional por plataforma:**
- [ ] Inclui seção Meta Ads apenas quando `meta_spend > 0`
- [ ] Inclui seção Google Ads apenas quando `google_spend > 0`
- [ ] Inclui as duas quando ambas > 0

**Tasks que executa:**
- [ ] `tasks/generate-report.md`

### agents/whatsapp-writer.md

**Identidade:**
- [ ] `tier: 1`
- [ ] `squad: gestor-trafego-stark`

**Saudação por horário:**
- [ ] 05h–11h59: "Bom dia"
- [ ] 12h–17h59: "Boa tarde"
- [ ] 18h–23h59 e 00h–04h59: "Boa noite"

**Nome personalizado:**
- [ ] Usa `nome_whatsapp` de `data/clientes.yaml`
- [ ] Formato: "[SAUDACAO], [NOME_WHATSAPP]!"

- [ ] Quando conversas = 0: omite linha de CPL completamente (não mostra "CPL: R$0,00")
- [ ] Quando conversas > 0: exibe CPL formatado com 2 casas decimais e símbolo R$
