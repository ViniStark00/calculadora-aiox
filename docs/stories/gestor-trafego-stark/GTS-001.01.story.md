# GTS-001.01 — Estrutura Base do Squad

## User Story

**Como** gestor de tráfego (Vinicius ou Gustavo),
**quero** que o squad `gestor-trafego-stark` tenha um manifest, briefing e documentação claros,
**para que** qualquer sessão saiba o que o squad faz, quais agentes existem e como acioná-los.

---

## Contexto

Este é o primeiro arquivo implementado. Sem `squad.yaml`, o sistema AIOX não reconhece
o squad. Sem `CLAUDE.md`, os agentes não têm identidade, voz ou restrições definidas.
Sem `README.md`, novos usuários não sabem como usar.

Os arquivos devem ser escritos do zero — **não copiar** dos squads antigos.
Use os arquivos originais apenas como referência de formato e conteúdo.

Referências de formato:
- `squads/gestor-trafego-vinicius/squad.yaml` → estrutura do squad.yaml
- `squads/gestor-trafego-vinicius/CLAUDE.md` → regras de voz do redator
- Agentes do squad Gustavo → tom direto e operacional do stark-chief
