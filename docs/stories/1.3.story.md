## Story

**As a** usuário da calculadora,
**I want** usar funções como `sin(30)`, `log(100)`, `√(16)` e `5!` clicando nos botões científicos,
**so that** eu possa realizar cálculos avançados além das quatro operações básicas.

## Acceptance Criteria

1. `sin(30)` em modo DEG retorna `0.5`
2. `sin(0.5236)` em modo RAD retorna aproximadamente `0.5` (π/6 radianos)
3. `cos(60)` em modo DEG retorna `0.5`
4. `tan(45)` em modo DEG retorna `1`
5. `asin(0.5)` em modo DEG retorna `30`
6. `acos(0.5)` em modo DEG retorna `60`
7. `atan(1)` em modo DEG retorna `45`
8. `ln(1)` retorna `0`; `ln(2.718281828)` retorna aproximadamente `1`
9. `log(100)` retorna `2`; `log(1000)` retorna `3`
10. `sqrt(16)` retorna `4`; `sqrt(-1)` exibe `Erro: raiz de número negativo`
11. `abs(-5)` retorna `5`; `abs(3)` retorna `3`
12. `fact(5)` retorna `120`; `fact(0)` retorna `1`; `fact(21)` exibe `Erro: máximo 20!`; `fact(-1)` exibe `Erro: fatorial de inteiros`
13. Botão `x²` insere `^2` e ao pressionar `=` calcula corretamente: `3 x²` → `9`
14. Botões `π` e `e` inserem as constantes e calculam: `π * 2` → `6.283185307`

## Dev Notes

### Estrutura do `ScientificFunctions.apply()`

```javascript
apply(fn, x) {
  switch(fn) {
    case 'sin':  return Math.sin(this.toRad(x));
    case 'cos':  return Math.cos(this.toRad(x));
    // ...
  }
}
```

### Conversão DEG ↔ RAD

```javascript
toRad(x)  { return this.mode === 'deg' ? x * Math.PI / 180 : x; }
fromRad(x){ return this.mode === 'deg' ? x * 180 / Math.PI : x; }
```

### Fatorial — implementação iterativa

```javascript
fact(n) {
  if (!Number.isInteger(n) || n < 0) throw new Error('fatorial de inteiros');
  if (n > 20) throw new Error('máximo 20!');
  let r = 1;
  for (let i = 2; i <= n; i++) r *= i;
  return r;
}
```

### Atenção: funções já recebem o argumento avaliado

O `evalRPN()` já avalia o argumento antes de chamar `ScientificFunctions.apply()`. Então `apply('sin', 30)` recebe o número `30`, não a string `"sin(30"`.
