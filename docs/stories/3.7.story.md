## Story

**As a** gestor de tráfego pago usando o squad relatorio-semanal,
**I want** que a mensagem WhatsApp gerada ao final do pipeline seja um convite simples com link ao relatório (sem exibir métricas),
**so that** o cliente receba uma mensagem limpa convidando-o a clicar no link e ler o relatório completo — e o pipeline a gere automaticamente, sem precisar ser solicitada.

## Scope

**IN:**
- Novo template único de convite em `templates/whatsapp-template.md` (substitui os 3 templates atuais com métricas)
- Simplificação de `agents/whatsapp-writer.md`: remover lógica de seleção de plataforma e regra de highlight; adicionar saudação por horário
- Reforço do step 11 em `agents/relatorio-chief.md` com nota explícita de obrigatoriedade automática

**OUT:**
- Mudanças em outros agentes (`coletor`, `redator`, `publicador`, `quality-gate`)
- Alterações no fluxo do pipeline (`squad.yaml`, `workflows/`)
- Mudanças em `config/clientes-config.yaml`
- Envio real da mensagem via API (o agente exibe a mensagem para copiar — envio manual pelo gestor)

## Acceptance Criteria

1. `templates/whatsapp-template.md` contém exatamente **1 template** (sem variações META-only / Google-only / META+Google)
2. O template usa os campos: `[SAUDACAO]`, `[DD/MM]` início, `[DD/MM]` fim, `[CLIENTE]`, `[LINK]`
3. A mensagem **não exibe métricas** (sem CPL, sem investimento, sem contagem de conversas, sem highlight)
4. A mensagem contém convite explícito para clicar no link do Reportei
5. Saudação é determinada pelo horário local: **Bom dia** (00h–11h59) / **Boa tarde** (12h–17h59) / **Boa noite** (18h–23h59)
6. `agents/whatsapp-writer.md` **não contém** a seção "Regra de seleção de plataforma"
7. `agents/whatsapp-writer.md` **não contém** a seção "Regra para linha de highlight"
8. `agents/whatsapp-writer.md` lista apenas os campos do handoff necessários: `cliente`, `periodo_inicio`, `periodo_fim`, `link`
9. `agents/relatorio-chief.md` step 11 contém nota: `— OBRIGATÓRIO, executa automaticamente sem aguardar solicitação`
10. Ao rodar o pipeline para qualquer cliente, a mensagem de convite aparece ao final **sem que o gestor precise pedir**

## Dev Notes

### Contexto do problema
O `whatsapp-writer` já está no step 11 do `relatorio-chief` e deve rodar automaticamente. O template atual exibe métricas (CPL, investimento, conversas) — o usuário quer apenas um convite limpo com link para o relatório publicado na Timeline do Reportei.

### Arquivos a modificar
| Arquivo | Tipo de mudança |
|---------|----------------|
| `squads/relatorio-semanal/templates/whatsapp-template.md` | Substituir 3 templates por 1 template de convite |
| `squads/relatorio-semanal/agents/whatsapp-writer.md` | Simplificar lógica, remover métricas, adicionar saudação |
| `squads/relatorio-semanal/agents/relatorio-chief.md` | Reforçar step 11 (1 linha) |

### Arquivos que NÃO devem ser modificados
- `squad.yaml` — pipeline_flow já está correto
- `workflows/weekly-report-pipeline.md` — fluxo já correto
- `config/clientes-config.yaml` — não relacionado

### Exemplo do output esperado após a mudança
```
MENSAGEM WHATSAPP — IMCP
════════════════════════════════════════════════════
Olá, Boa tarde!

Segue o relatório de tráfego da semana *11/05 a 17/05*, IMCP.

Para acessar, clique no link abaixo:
🔗 https://app.reportei.com/projects/839737
════════════════════════════════════════════════════
📋 Copie a mensagem acima e envie ao cliente via WhatsApp.
```

### Complexidade
Baixa — edições de texto em 3 arquivos Markdown. Sem lógica de código, sem dependências externas, sem novos arquivos.

- O `link` já é montado pelo `publicador` antes do `whatsapp-writer` — campo disponível no handoff
